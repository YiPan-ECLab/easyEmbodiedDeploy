1 · 连接从臂

未连接设备

回零：六个关节回到 0°，默认保持夹爪宽度。急停：阻尼停机，不回零。连接不会自动移动。

设备与恢复（反馈异常时展开）

反馈缺失时可恢复从臂反馈；不释放电机，不回零。整个模块只连接从臂。机身按键示教须用机身按钮退出。

下一步：连接从臂；也可以选择模拟器熟悉操作。
更多录点与控制方式

录制一个位置，随时重复使用

  1. 选择从臂，用机身示教按钮进入可拖动状态。网页不会释放电机。
  2. 拖到目标位置，填写名称，点击「录制当前点」。可以连续录多个点。
  3. 录完用机身按钮退出示教；点击执行会自动结束网页录点、必要时先平滑回零。

连续录点只读取反馈，不改变电机供电。拖动由机身示教按钮控制；网页按钮不提供重力补偿。

运动与衔接参数（通常无需调整）

距离较大时自动延长运动时长。连续关节点支持平滑衔接；末端点平滑起停。policy Hz 只决定 VLA 动作队列的取出频率。

共享 VLA 模型库

每个模型单独命名、配置和预加载，可像关键点一样多次添加到工作流。步骤引用模型；修改配置后，引用它的步骤一起更新。

GPU 与模型驻留

正在读取 GPU…

同一 GPU 可加载多个模型，需有足够显存。模型卡片可直接选择设备；批量预加载使用各自保存的设备。空闲模型主要占显存，后台加载、预热或推理会竞争算力。

点击「保存模型配置」立即写入 datasets/workflows/model_library.json，无需先保存工作流。所有工作流共享模型配置；checkpoint 权重保留原路径。
