# 相机标定：前端操作流程

工作台 → **相机标定**。默认使用相机出厂内参，无需先做内参重标定。模块只读从臂位姿，不控制机械臂运动；采集结束、设备释放后再打开标定相机。

## 1. 采样并求解

1. 选择任务 → 核对相机序列号 → 勾选「只读对应从臂法兰位姿」→ **打开相机**。
2. 填写标定板参数、记录名称、安装版本 → **新建标定记录**。同一套安装用相同版本；相机或基座位置改变后换版本并重新标定。
3. 按任务固定设备：

   | 任务 | 固定什么 | 移动什么 |
   |---|---|---|
   | 左腕 / 右腕 | 标定板固定在环境；相机固定在对应法兰 | 对应机械臂 |
   | 全局 → 左 / 右 base | 全局相机和基座固定；板刚性固定在对应法兰 | 对应机械臂与板 |

4. 样本用途选「参与求解的标定样本」。每换一个姿态：停稳 → **检测角点** → 确认角点 0 始终是同一物理角点 → 勾选静止确认 → **保存求解样本**。方向不一致时调整「角点原点方向」再检测。
5. 采集 **15–25 个不同位置、多轴旋转的姿态**（至少 8 个）→ **求解当前记录**。切换任务前先 **关闭相机**，分别完成所需记录。

## 2. 用新姿态独立验证

1. 求解后，**保持刚才板与环境 / 法兰的固定关系**；样本用途改为「独立验证」。
2. 换 3–5 个未参与求解的姿态，停稳、检测、确认 → **保存独立验证样本**。
3. 查看「独立验证」中的平移、旋转、重投影误差。参考阈值为 **5 mm / 2° / 2 px**；超差先检查板是否移动、角点方向及标定质量。

验证样本不参与求解。增加 / 删除求解样本、更换内参或重新求解后，旧验证自动失效，需要重新验证。

## 3. 可选：检查双臂是否转换一致

1. 完成同一安装版本的 **左腕、右腕、全局 → 左 base、全局 → 右 base** 四项外参。
2. 将**同一块板**固定在两只腕部相机都能看到的位置。分别选择左腕、右腕记录并打开对应相机，样本用途选「双臂检查观测」，填写相同场景名称 → 停稳、检测、确认 → **保存双臂检查观测**。两次之间板不能动，物理原点 / 方向必须一致。
3. 在导出列表勾选四项结果 → 展开「双臂统一到左基座的一致性检查」→ **载入所选记录的腕部观测** → 选择左右同一场景 → 勾选固定板确认 → **检查双臂一致性**。

这里比较的是两次独立观测得到的**同一块板在左基座中的位姿**。可更换板的位置、场景名称重复检查；无需让两个法兰重合。

## 4. 导出

勾选需要的已求解记录 → **导出所选结果** → **复制标定包路径**或**下载 JSON** → **关闭相机**。

同时导出全局对左右 base 两项时，自动附带：

- `T_left_base_right_base`：右基座坐标 → 左基座坐标，`p_left = T_left_base_right_base × p_right`。
- `T_right_base_left_base`：上述变换的逆；平移单位均为米。
- 单项验证摘要与样本；选择四项外参时附带仍有效的双臂检查报告。

可只导出所需部分，不强制做独立验证；有超差或质量提示时，检查后再勾选「仍接受导出」。

## 采样失败时

保存会自动检查约 **0.35 秒**：反馈新鲜度 ≤250 ms、图像 / 位姿接收时间差 ≤100 ms、法兰变化 ≤2 mm / 0.5°、角点漂移 ≤2 px。提示过期时检查反馈，提示移动时停稳重试。

时间检查基于**主机接收时间**，不是硬件曝光同步。手动输入位姿仍可使用，但只能自动检查图像静止性，不能验证手填位姿的时效和机械臂静止性。这些检查仅用于标定，不改变采集、训练或部署频率。
